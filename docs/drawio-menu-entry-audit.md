# Draw.io 菜单入口核查

本文用于核查 Draw.io 页面顶部红框菜单中的功能，判断它们是否已经在页面其他位置提供了入口，以及后续哪些功能可以隐藏、哪些功能必须迁移到 MarkNotePro 外层原生菜单。

## 核查范围

当前 MarkNotePro 使用 Draw.io 的本地嵌入模式：

- `embed=1`
- `proto=json`
- `libraries=1`
- 页面内保留 Draw.io 工具栏、左侧图形库、右侧样式面板和画布右键菜单
- 红框菜单为 `文件`、`编辑`、`查看`、`排列`、`其它`、`帮助`

“其他途径”只记录 Draw.io 页面已经存在的入口，不把未来的 MarkNotePro 外层菜单算进去。

## 标记说明

| 标记 | 含义 |
| --- | --- |
| 已有 | 页面中已经有明显、直接的替代入口 |
| 条件已有 | 只有选中对象、选中连接线、进入文本编辑或打开对应面板后才有 |
| 间接 | 可以通过其他页面操作完成，但入口不等价或不明显 |
| 没有 | 当前页面没有发现同等入口，建议保留或迁移到外层 |
| 待确认 | 功能受 Draw.io 配置、文件类型或运行环境影响，需要实际点击确认 |

| 草稿 | Draw.io 草稿保存设置 | 没有 | 当前由 MarkNotePro 标签和文件保存接管 | 建议隐藏 |

## 七、页面入口与菜单功能的结论

### 已经被页面入口覆盖，优先考虑隐藏

- 保存、退出
- 撤销、重做
- 删除、复制、剪切、粘贴、复制副本
- 放大、缩小、页面缩放
- 网格、页面视图、背景、纸张尺寸、连接箭头、连接点、辅助线
- 编辑数据、编辑样式、编辑链接、编辑文本
- 插入图片、插入链接、插入表格、插入图形
- 编组、进入分组、退出分组、展开、折叠
- 主题和语言（因为应由 MarkNotePro 统一）

### 页面有替代入口，但入口不完整，不能直接删除

- 导入、导出
- 页面设置
- 对齐、分布、排列层级
- 连接线方向、清除连接点、自动调整大小
- 编辑提示、编辑备注、编辑几何、多边形、连接点

### 当前主要依赖菜单，迁移到外层时应优先保留

- 查找和替换
- 大纲、图层
- 导出 PNG/JPG/SVG/PDF/HTML/XML/JSON/GIF
- 导入 VSDX、CSV、PlantUML 等特殊格式
- 自动布局及所有布局子菜单
- 打印
- 原始 XML 导出

### 与 MarkNotePro 职责冲突，建议永久隐藏

- Draw.io 独立语言
- Draw.io 独立主题
- Draw.io 配置
- Draw.io 自动备份和草稿
- Draw.io 检查更新
- Draw.io 独立退出逻辑（由 MarkNotePro 标签关闭接管）

## 八、建议你填写的字段

你可以直接在每个表格后增加一列“处理意见”，使用以下值：

- `保留在 Draw.io 页面`
- `迁移到 MarkNotePro 外层菜单`
- `隐藏`
- `暂不处理`

本表的“已有/条件已有”只表示页面当前确实存在入口，不代表入口体验一定足够好；特别是右侧样式面板和选中对象右键，仍需要实际测试不同选中状态。
